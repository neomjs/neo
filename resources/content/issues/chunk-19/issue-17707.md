# The split proof governs ai/**; the inventory governs only ai/scripts/**

## Context

Epic #17500 requires the zero-residue inventory and paired plane-boundary proof before relocation. #17525 and #17645 delivered the existing registry and launch/dependency authority; both are closed. The current proof still emits one pre-relocation blocker whose successor owner points back to that closed lineage.

Exact source-bound receipt on `origin/dev@e318269c8cd73c2ccbfc70655d3529699e45df6c`:

```json
{
  "sourceBinding": {"bound": true, "sha": "e318269c8cd73c2ccbfc70655d3529699e45df6c", "dirtyPaths": []},
  "instrumentErrors": [],
  "inventoryLineage": [{
    "class": "topology-edge-closure-unregistered-module",
    "identity": "290 module(s)",
    "identityCount": 290,
    "successorOwner": "the AgentOS extraction inventory (#17525 / #17645 lineage)",
    "preRelocationBlocker": true
  }]
}
```

This is a new successor. Reopening either resolved producer ticket would rewrite its delivered contract.

## The problem

The inventory and the paired proof use different module populations:

- `agentOsExtractionInventory` derives an exact `script-module` surface for `ai/scripts/**/*.mjs`: 162 current rows.
- The repository has 776 tracked `ai/**/*.mjs` modules.
- `agentOsPlaneBoundaryProof` walks every module reached from an Edge launch root and declares the registry region to be all `ai/**`.
- Its `dispositionByIdentity` map currently consumes **every inventory surface by bare identity**, not an explicit module-placement surface.

That last point creates two failures at once:

1. 290 Edge-reached modules have no row whose bare identity matches, so they are aggregated as unregistered.
2. A module can be accidentally classified by an unrelated surface with the same string identity. Example: `ai/graph/storage/SQLite.mjs` reads Cloud in the module walk because a `plane-opener` row happens to carry that path—not because module custody was dispositioned.

The proof therefore cannot distinguish “this module is intended Cloud and Edge reach is a severance blocker” from “no module authority exists,” except where another population happens to collide by path.

## Why reachability cannot become the missing authority

A current-head reach census over the 75 dispositioned launch roots yields:

| observed reach | tracked modules |
|---|---:|
| Edge-only | 98 |
| Cloud-only | 56 |
| both | 272 |
| neither | 350 |

Observation is not placement authority. Treating “both” as `shared` would auto-admit 272 modules into a package ADR-0040 permits only for pure, driver-free, capability-free modules with explicit cross-plane need. Many of those 272 are exactly the current store-edge violations the proof must keep red. The 350 unreachable modules still need custody before a move; silence is not `retire`.

## Intended solution

Promote full Brain-module placement into one explicit registry surface and make the proof consume only that authority:

1. Derive every tracked `ai/**/*.mjs` identity.
2. Materialize exactly one `edge | cloud | shared | stays-engine | retire` decision for each under a dedicated module-placement surface.
3. Migrate/replace the narrower `script-module` authority so one module cannot have two placement owners.
4. Permit compression only when its exact expansion is drift-guarded: a new/deleted file, overlapping rule, empty exact override, or changed expansion must fail until the registry decision is updated. A blanket `ai/** → edge/cloud` fallback is forbidden.
5. Build the plane proof's `dispositionByIdentity` from module-placement rows only; unrelated launch/config/opener rows must never classify a module by string collision.

The emitted receipt remains exact-identity and SHA-bound even if the source registry groups identities for maintainability.

| tracked Brain modules | ADR-0040 §2.2/§2.4 + extraction registry | every tracked `ai/**/*.mjs` has one explicit plane/custody decision | fail on missing, stale, overlap, invalid disposition, or unpinned expansion | exact current-tree receipt + add/delete/overlap mutations |

| paired proof | #17533 / ADR-0040 §2.6 | zero unregistered-module findings once authority is complete; other topology findings remain truthful | no suppression or reclassification-to-green | exact proof receipt before/after |

## Acceptance criteria

- [ ] The inventory derives all tracked `ai/**/*.mjs` modules (776 at the filing head) and materializes exactly one module-placement row per identity.
- [ ] Existing `script-module` decisions are migrated without creating a second placement authority.
- [ ] The registry fails on a newly added module, retained deleted identity, overlapping/conflicting rule, invalid disposition, missing source/rationale, or unpinned rule expansion.
- [ ] The plane proof consumes only module-placement rows for module custody; a same-path `plane-opener`, `launch-root`, config, or workflow row cannot classify a module.
- [ ] `shared` remains governed by ADR-0040's admission rule. Current dual-plane reach is never auto-promoted; any population change that contradicts the ADR's “exactly one” statement triggers its amendment gate.
- [ ] A current-head paired static proof has zero `topology-edge-closure-unregistered-module` findings and zero instrument errors.
- [ ] Existing Edge→Cloud/store findings remain red under their intended Cloud module rows; completing membership authority must not reduce topology findings by omission.
- [ ] The inventory and proof receipts remain deterministic, exact-identity, and source-SHA-bound.
- [ ] Focused mutations cover both residue directions, cross-surface identity collision, shared-admission rejection, and a known Edge→Cloud positive control.

## Out of scope

- Severing any Edge→Cloud/store dependency (#16202 / #17627 lineage).
- Moving files or creating the new package manifests.
- Reclassifying package dependencies, workflow dispositions, or out-of-`ai/**` consumers.
- Changing the runtime-denial harness or computed-edge registry.
- Treating current reach as the placement decision.

## Avoided traps

- **Reopening #17525 or #17645.** Both delivered their scoped populations; this is the new population their consumer exposed.
- **Making the 290 identities disappear by weakening the proof.** ADR-0040 requires membership before relocation; silence is not authority.
- **Auto-classifying by current reach.** Cross-plane reach includes the violations the split exists to sever.
- **Allowing surface collisions to stand in for module custody.** A durable-plane opener and a module placement are different claims even when their path strings match.
- **A blanket prefix default.** It makes new modules silently inherit a plane and defeats the zero-residue gate.
- **A flat 776-object ledger with repeated prose.** Grouping is allowed, but only with exact expansion/drift guards and exact emitted identities.

## Decision Record impact

Aligned with ADR-0040 §2.2, §2.4, and §2.6. If the full module census changes the accepted shared population, ADR-0040 requires an amendment; this ticket does not pre-approve that outcome.

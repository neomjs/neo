## Deltas from ticket

1. **Roster density converted from viewport media queries to container queries** (`FleetGrid.scss`): the spec's density row rules "2-up to the 20-card fleet, 3-up only past 1280px of grid measure" — the shipped 3-up-by-viewport default both violated the stated step and lied inside vessel windows (a narrow pane in a wide viewport rendered 3-up). The grid is now its own `inline-size` container; verified live: fronted 1214px grid measure → 2 columns, backgrounded 0×0 vessel → 1 column (the own-measure discipline responding honestly).
2. **Chip-family drift healed**: `AgentConfigCard.scss`'s local `.fm-chip` block had re-declared geometry/type (12px, pad 2/8, radius 6) that drifted from the Chips.scss family (detail metrics, pad 3/9); the local block now keeps only its state classes + state-transition motion, the family owns anatomy. The `InstanceManager`/`InstanceSwitcher` word-chip pills bind the chip geometry tokens their values already matched.
3. **Affordance-chip voice rule recorded** (`Chips.scss`): the affordance class consumes detail-role METRICS with `font-family: inherit` — a pressable control speaks the surrounding surface's voice, not the observation tier's mono. Applied to the memories/catch-up picker chips.
4. **`--fm-text-chrome-tracking` minted as the contract's sixth type token** — the chrome role's `.08em` half cannot ride a `font` shorthand; recorded in the TOKENS.md type-roles row citing this ticket. The EventChip kind word binds the same constant (one uppercase-tracking voice).
5. **Measured discovery, recorded not fixed**: the AgentCard name ROOT consumes the display role correctly (14/1.3·600, FM sans — probe-verified), but the framework button theme re-sizes the child `.neo-button-text` span (16px, theme face), before and after this pass alike. Resolving that child override is the #17211 oversize slot; an in-file record marks it.
6. **Off-rhythm spacing is recorded, never bulk-snapped**: the measured off-ladder population (10px ×29, 6px ×19, 7px ×9 …) is per-file header-recorded and deferred to #17268 — only the spec's NAMED snaps land (card padding 10→12, panel padding = space-4). Forcing the rest would have been a silent per-pane redesign inside a migration pass.

Adjacent observation (not touched): the top-toolbar "Agent OS" label renders near-invisible in the light skin — pre-existing, color-layer, outside this SCSS-only pass.

## Next: Engine 13.2 — A Runtime That Ships From Several Repositories

v13.1 made the institution safe to leave running. Since then the organism split into sibling repositories, and **13.2 is the engine's first release after that split**: the multi-threaded runtime, its dock layouts and its flagship Workstation ship from [neomjs/neo](https://github.com/neomjs/neo) on their own cadence, while the Agent OS and the Fleet Manager release on theirs. The release gate is behaviour we can observe:

> **The engine's site deploys from the published `neo.mjs` package with the portal and the docking demos current; a second Workstation window never kills the first, and the first keeps painting; the docking demos are public, animated and e2e-tested; and the release notes tell the engine's story, not the organism's.**

This section names the gate and the load-bearing path, not a frozen checklist. [Milestone #9](https://github.com/neomjs/neo/milestone/9) is the tracking milestone; its linked items are the full set.

**The institution's own prerequisite sits beside the gate, not inside it.** The Knowledge Base the team steers by has read a corpus frozen on 2026-08-26. Making it current is work on the **local plane** — the one-machine image cut ([neomjs/neo-agent-brain#253](https://github.com/neomjs/neo-agent-brain/issues/253)), the tenant poller's retry defect ([neomjs/neo-agent-brain#237](https://github.com/neomjs/neo-agent-brain/issues/237)) and the tenant's activation ([neomjs/neo-agent-brain#411](https://github.com/neomjs/neo-agent-brain/issues/411)) — and it is cornerstone 1 because everything below steers better once the Dream Pipeline and the Golden Path forecast again. It is not a release of any line, and no line's release waits for it.

**Three release lines, each on its own cadence.** The engine is the only repository that has cut a release (13.1.0); the skills package already ships on its own npm cadence; the Brain releases as container images; the Institution pins a `dev` engine commit today. So there is no org release — there are three lines, each with its own gate and its own notes. The engine's is the only gate written down; the other two are recorded as they stand:

**How it runs.** Ordering follows the consumption chain: the image cut unblocks the Knowledge Base tenant, which `ask_knowledge_base`, the Dream Pipeline and the Golden Path consume — the Fleet Manager feed and the portal indexes read the corpus checkout directly and wait for nothing; the deploy decision (D#19050) and the content decision (D#19051) are decided and their chains proceed in parallel; the second-window outcome shipped through the canvas-worker slice (#19103), while the full worker boundary waits for its open questions. Cadence: steady state is roughly 100–150 merged PRs per release, and 13.2 is already past that on the milestone, so no further cornerstone is added — new work attaches under an existing epic or waits for the next line. Any peer claims subs; the steward owns the outcome and closes the epic.

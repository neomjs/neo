Resolves #17554

Related: #17550

Neo now has a semantic list primitive for long fixed-height histories without importing Grid chrome or record-cardinality DOM. `Neo.list.Buffered` keeps the existing Store, ListModel, Navigator, `ul/li`, and component-row contracts while mounting only the viewport plus a symmetric row buffer between stable spacers.

Physical pool slots and logical records are separate truths. Surviving records retain their component slot where possible; list-item DOM stays in Store order; selection, focus, click mapping, sort/filter/load/recordChange, and prepend-heavy scroll anchoring all resolve through the logical record. A 5,000-record Store therefore owns nine components in the 5-visible + 2×2 fixture, not 5,000.

Evidence: L2 achieved (real Neo class + Store/Model/ListModel + VDOM-delta witnesses over 5,000 records, resize lifecycle, mutation, selection/focus, and anchor paths) → L2 required. Residual: none for this engine leaf; downstream consumer #17550 owns headed L3 scroll/product proof.

## Problem

The matrix could serve one dynamic port while a spec navigated to a different fallback port, and macOS row 5 remained `NOT_YET_MEASURED`. A green denial probe alone would be insufficient: the receipt has to traverse the real product gesture, prove same-instance continuity and JSON persistence, return home, close natively, and leave cleanup idempotent.

## Intended solution

- Make the runner's resolved port the sole authority consumed by every matrix worker/spec.
- Exercise real browser-context `window-management` denial and exact `NotAllowedError`.
- Drive the real G1 boundary gesture into exactly one tear-out vessel.
- Prove singleton component identity, exact mount/heartbeat transitions, and actual JSON perspective-writer acceptance while detached and returned.
- Close the vessel natively and prove one semantic home, cleared lifecycle maps, and repeated-terminal no-op.
- Promote only macOS row 5 to `PASS_FALLBACK`; retain the canonical Demo B competing-vessel red control and leave rows 4, 6, and 7 open.

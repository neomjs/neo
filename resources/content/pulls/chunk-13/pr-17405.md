Resolves #17402

The Playwright fixture is a second Bridge entrypoint and supplied no `cwd`, so `spawnBridge` refused wherever no Bridge was already listening — which is every clean container, and no maintainer seat. One line in the fixture, plus the guide sentence that made the contract false.

Evidence: L3 (live e2e on this host, real browser, real spawn — the refusal reproduced and then eliminated) → L3 achieved, no residual. The one arm this host cannot produce is a fully green run *through* the spawn path, and I tried twice: `NEO_NL_PORT` moves the node-side ConnectionService but not the browser app, and injecting `Neo.config.neuralLinkUrl` via `page.addInitScript` does not reach the app's bootstrap either. Both attempts spawned the Bridge **with no refusal** and then failed on `waitForSession` — the port split, not the fix. Freeing the app's default port means killing the seat's own live Bridge, which I would not do.

None substantive. AC-4 (guide states the contract) is delivered in the same commit rather than split, because the guide sentence is what made the defect invisible to an author — it sells the fixture on *not* managing the connection.

**Challenge (three edge-seams, all non-blocking):**

3. **Port-zero validation gap:** the daemon's envelope check rejects `undefined`/`null`/`''` but not `0`. The plugin guards it (`Number.isInteger(port)` throws), so it's unreachable today — but the daemon's own guard would pass a `0` port. A `> 0` check on port would make the daemon self-sufficient.

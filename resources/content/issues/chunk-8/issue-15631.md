# Scripted kinetic multi-window demo: popup drags across real OS windows

## Context

Operator direction (2026-07-21, Build Week submission window + standing demo boost): the current cut presents multi-window Neo *statically* — a detail panel already in a second window — while the engine's signature kinetic capability (animated drag of live panels across real OS windows, N popups, re-integration) is exactly what our e2e suite proves daily. The demo undersells the Body. Choreography v2: scripted popup drags performed deterministically, filmed, composited into the film's QT proof beat. Codex-weekly-reset gates only the *dialogue TTS* regeneration (Emmy's lane); visuals need nothing.

Live latest-open sweep: checked latest 20 open issues at 2026-07-21T07:35Z; no equivalent. A2A in-flight sweep: no competing claim (Emmy composites; Vega's #15624 is the anatomy leaf).

## The Problem

A live component crossing an OS-window boundary mid-gesture — still subscribed, still updating, identity intact, then re-integrating — is the single most legible proof of Neo's multi-threaded object-permanence engine. Static two-window shots cannot show it. The film's QT beat and the standing demo both deserve the kinetic version.

## The Architectural Reality

Everything needed is already shipped and proven:

- `FleetCockpit.popOutAgentDetail()` + `reattachAgentDetail()` — click pop-out with reparent-never-recreate (`detachedDetailPane` re-adoption).
- Gesture tear-out bookkeeping exists cockpit-side (the animated-drag path, separate from click pop-out).
- `operator-mailbox` is a dock-pane item — the 2-popup bonus rides the same dock machinery (verify its pop-out path first).
- Scripted gesture drive via `InteractionService`/Neural Link — the same path `DemoBCrossWindowDragNL` executes headed on this host.
- macOS `screencapture -v` video capture proven by Emmy's capability probes.
- #15629 (film-floor) merged: recapture materializes themes first (#15449 discipline).

## The Fix

1. Verify the `operator-mailbox` pane's pop-out/tear-out path (10 min).
2. Author the deterministic shot list + scripted drive: drill into a resident → pop the detail out → animated drag into the right-side space → pop the mailbox out → drag it too → re-integrate the detail (the return proof).
3. **Framing (operator constraint):** only a LITTLE additional space right of the main window — ~4:1 ratio (main content stays dominant; the popup is the mover, not the stage). Ratio is explicitly challengeable at shot-list review.
4. Fallback: popup moved on top of the main viewport (single capture region) if desktop framing misbehaves.
5. Two identical takes via the scripted drive; keep the cleaner (determinism receipt). Stage restored after each take (the walkthrough contract).
6. Capture on this host (proven headed seat) with materialized themes; hand footage + timing map to Emmy for compositing.

# Bind the Agent OS cut manifest to the freeze line

## Context

Wave 3 may not copy from a moving source. This leaf binds the cut to the operator-declared freeze and converts the accepted inventory/proof/runway state into one machine-readable receive contract.

The current repo still changes rapidly; a local proof run against a dirty, stale checkout correctly refused SHA binding. The final receipt therefore runs only on the clean frozen source SHA and names every prerequisite by immutable identity.

## The Problem

D#17782 names wave order, #17500 names accepted topology, the extraction inventory names population, and #17783/#17784 name upstream substrate. None alone binds the exact source/target SHAs, receive set, in-flight lanes, rollback pair, tracker set, and terminal removal predicate.

Without one cut manifest, different PRs can each be locally correct against different repository revisions.

## The Architectural Reality

- `agentOsExtractionInventory.mjs` already derives source-owned identities and bidirectional residue.
- `agentOsPlaneBoundaryProof.mjs` already separates instrument errors from topology findings and refuses dirty SHA attribution.
- ADR 0040 owns Host Edge / Cloud / shared placement and no-history-rewrite.
- D#17782 declares the freeze; Wave 2.5 owns the frozen 330-ticket baseline and disposition of every sanctioned post-freeze runway-ticket delta; Wave 0 owns the image pin + named verified bundle.
- The new manifest belongs with the existing extraction diagnostics/registry authority; extend that role rather than create a parallel census.

## The Fix

Extend the existing extraction authority to emit and verify a `wave3-cut-manifest.v1` envelope at the frozen SHA. It records source and target revisions, exact move/stay/retire identities and target paths, package manifests, prerequisite issue/PR heads, rollback image pin + named verified bundle receipt, in-flight PR/lane dispositions, tracker baseline receipt plus explicit sanctioned-delta receipt, peer-owned learn/ADR dependency, receive verification gates, and the terminal Engine removal allow-condition.

The verifier fails closed on dirty/unbound source, stale target, non-zero pre-relocation blocker, unresolved in-flight lane, missing prerequisite, an unmerged/unpinned ADR 0040 §2.7 learn-custody correction, receipt mismatch, or any identity absent from either source authority or target plan.

## Acceptance Criteria

- [ ] Manifest binds a clean frozen `neomjs/neo` SHA and current `neo-agent-brain/dev` target SHA; dirty/unbound input REDs.
- [ ] Every moving, staying, shared, and retiring identity has exactly one target/disposition; both source↔authority and source↔target residue are empty.
- [ ] Current plane proof runs at the freeze SHA with zero instrument errors; every pre-relocation blocker is discharged or the manifest refuses.
- [ ] Prerequisite heads/receipts for Wave 0, #17783, #17784, Wave 2.5, D#17644, and the learn/ADR stream are immutable and read back.
- [ ] ADR 0040 §2.7's learn-custody correction is merged and pinned: legacy Engine-stay language no longer conflicts with D#17782's Brain-owned `learn/` / 40-ADR disposition; the manifest verifier REDs while that amendment is absent or stale.
- [ ] In-flight PR/lane ledger covers every cut-touching branch and claim; omission/replacement at equal count REDs.
- [ ] Tracker population is SHA/time-bound to the completed 330-row baseline plus an explicit ledger of every sanctioned post-freeze runway-ticket delta; each row distinguishes transfer, close-with-pointer, resolve-pre-split, and stay-Engine.
- [ ] Rollback carries both the Wave-0 image pin and named verified bundle; either missing half REDs.
- [ ] Receive order and terminal removal predicate are machine-readable; no Engine removal can pass before every receive receipt is green.
- [ ] Output is deterministic, schema-versioned, human-readable, and linked on the Wave-3 Epic and D#17782.

## Out of Scope

- copying files or opening receive/removal PRs;
- performing tracker transfers;
- re-declaring the already-active freeze;
- changing topology classifications merely to make the manifest green.

## Avoided Traps

- **Handwritten file list:** duplicates the inventory and decays.
- **Count-only receipt:** permits same-count identity substitution.
- **Dirty-tree SHA claim:** attributes working-tree reality to a commit.
- **Image-only rollback:** restores code but not durable state.
- **Runway prose as machine gate:** humans can read order that automation cannot enforce.

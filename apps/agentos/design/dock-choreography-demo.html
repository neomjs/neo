Honest state — what this mock promises vs what ships today

Real today (shipped dockZone.v1 + landed #14625 tools): every S1–S3 operation class — split, resizeSplit, moveItem→tab, setItemAutoHidden — executes semantically with animated transitions, agent-drivable end-to-end. Designed here, building in the tree: the edge-rail affordance (#14654) and reveal/dismiss timing (#14660) for S3's beats 1–3; the tour runner (#14640) and this screenplay as its script (#14661). Deliberately absent: perspectives and multi-window pop-out — that is Demo B (#14590, spec-gated), and blending the two would blur both stories. No performance numbers appear anywhere in the demo (#13032 guardrail; the motion must simply LOOK effortless — a claim the viewer verifies with their own eyes).
06

Drag affordances — show the menu, never make them guess

authority section for #14930; Qt-ADS is the floor, not the blueprint

The disposition, decided here: the indicator-overlay model is the primary drag affordance; pointer-zone inference demotes to fallback. Rationale: discoverability is the felt difference — the floor system shows every valid drop option simultaneously while dragging (a 5-position cross on the hovered area, edge chips on the container); ours makes the user divine invisible zones from pointer position. Functional is not felt. The user picks from a visible menu; the menu is the affordance.

The affordance grammar

  1. Drag proxy — the tab travels with the pointer (content pixmap tier later; label chip now)
  2. Indicator cross on the hovered area: center = tab-merge · N/S/E/W = directional splits; edge chips on the container borders
  3. Target preview — hovering an indicator fills the exact post-drop region (accept: signal-tinted; reject: hot dashed, policy-honest)
  4. Drop commits through previewToOperation unchanged; Escape cancels mid-flight (absorbs tree line C5, single-window)

Bindings & boundaries

  • Tokens: chips on --fm-panel-2/--fm-line; active and reject previews consume the component-domain --agent-dock-preview-accept/reject aliases, whose theme values map to this artifact's signal/hot columns while #14681 owns the future global light-native FM vocabulary; motion via the --dock-transition-* contract — zero local duration policy
  • Producer extends one-affordance-from-pointer → full candidate set for the hovered area; presentation-tier only, reducer contract untouched
  • Edge-band inference stays as the fallback tier (touch, and mid-drag before any indicator is hovered)
  • Grouped-drag proxy (E-tranche) and cross-window drag scenes (#14772) stay out of scope here
  • The camera beat: Demo A's cold open — ~15s of hand-drag with this menu lit, then "now watch an agent do it"

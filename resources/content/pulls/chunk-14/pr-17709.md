Resolves #17711

> 🌿 A bundle folder can no longer stand in for the export that was supposed to fill it, and a single fault can no longer report itself as the only one.

Related: #16617

Two test-integrity defects in `backup.spec.mjs`, both measured before being fixed. #17711 was split out of #16617 so this work has an honest close target; the umbrella stays open for its remaining criteria (populated/empty-plane negative control, residual static check, enforcement reach).

**1. A folder stood in for its export.** The spec asserted five bundle subfolders exist. `runBackup` ensures every layout folder *before* any subsystem runs, so existence proves nothing about contents — and the list was stale: seven folders are created, five were named, leaving `mailbox` and `ledgers` outside every assertion in the file. Both export nothing here. Replaced with the property: each recovery substrate must reach integrity `pass` with source/bundle parity above zero; each copy subsystem must have copied rows or carry the `note` naming its absent source.

**2. One failure hid forty-two tests.** `test.describe.configure({mode: 'serial'})` sat at file scope, so any fault in the orchestrator block skipped everything after it. Moved onto the one block that earns it — the only one mutating the KB/MC singleton accessors across its hooks.

Evidence: L3 (in-process execution plus three reverted source mutations; a pure Node/Playwright unit surface the sandbox reaches fully) → L3 required (two ACs are worded "red-proved by mutation" and "measured before/after"). No residuals.

## AC Evidence

| AC-1 | Every subsystem asserted EXPORTED or named its absent source — MUTATION A: dropping the `note` from `copyJsonlSource`'s absent-source return fails with `mailbox: {"copied":0}` at line 204 |
| AC-2 | Folder assertion is an equality against the bundle's own layout (all eight entries incl. `bundle-meta.json`), not a hand-counted subset — an unasserted eighth folder fails it |
| AC-3 | No count pinned for `graph`; the arm asserts integrity `pass` + parity, which is unreachable at zero, so it holds whether the run-scoped test graph store is populated or empty |
| AC-4 | Orchestrator-block failure no longer aborts the other three — MUTATION C: injected `beforeAll` throw gives **before 1 failed / 42 did not run / 2 passed · after 1 failed / 22 did not run / 22 passed** |
| AC-5 | `serial` still declared on the singleton-mutating block (`backup.spec.mjs:65`); the other three blocks import pure functions into pid+timestamp temp dirs |
| AC-6 | Focused spec **45/45 green** at `d4c4d97304` |

## Deltas from ticket

**The parent ticket's premise for AC-1 did not survive execution, and the AC survived anyway.** #16617 claimed `#exportGraph` always takes its uninitialised-graph branch in a host run, so `graph/` is created while nothing is exported. Measured: `graph` exports **17 elements** and reaches integrity `pass` — the `UNIT_TEST_MODE` `graphTest` formula wires it, which #16617's body had already recorded as "safe-by-construction" two corrections earlier and then reasoned past. That is the third wrong mechanism for this spec on that ticket; #16617's body now carries the retraction and the measurement.

The AC survived because the vacuity had **moved**, not vanished — to `mailbox` and `ledgers`. Writing the property rather than the observation is what makes it premise-independent: MUTATION B below forces the exact branch the ticket described, and the new assertion still catches it.

**AC-4's shape was corrected on the parent, not weakened.** #16617's wording also demanded "a failure count without a `did not run` count for that file" — a different *set* from "42 sibling tests": 20 tests in unrelated blocks versus all 42. Playwright skips the remainder of a serial scope after any failure, so the residual 22 are the orchestrator block's own tests, which genuinely depend on the fixture that failed. #17711's AC-4 states the reachable property and its Out of Scope records why zero is not it.

**Found while sizing, deliberately not fixed here:** `copyJsonlSource` returns `{copied: jsonlFiles.length}` with no `note` for a source directory that exists but holds zero `.jsonl` files (`backup.mjs:1452`, warn-only). A genuine production silent-zero that the new assertion fails on — repairing production behavior does not belong in a test-integrity PR. Recorded on #16617.

Resolves #15270

The S1 **view** half from the graduated FM record (D#15249): `AgentDetail` grows a Status/Mailbox tab structure, and the Mailbox tab renders the drilled resident's active-inbox mirror — flat-chronological with thread-collapse where `partOfThread` exists, paginated, and labelled with **pane-level data-as-of freshness** (never per-row: messages are immutable timestamped facts, so per-row freshness is noise). Object permanence drove the placement: the mailbox belongs to the agent object, so it is a tab inside the resident's inspector, not a parallel surface. **The pane renders; it never fetches** — it consumes the #15269 adapter's frozen snapshot through the possession seam, exactly like the wiring will.

**Read-only is structural, not configurational.** No mark-read, no reply, no mutation verb exists anywhere in the pane's vdom — the record's MUST-NOT (operator-side mark-read would mutate the agent's own turn-start signal and silently swallow peer handoffs). This is asserted twice: a unit spec pins the absence, and the live e2e asserts **zero** `button, input, textarea, select, a` render inside the mounted pane. Reply-as-operator stays deferred to v13.3 as chat's companion — the record pre-answers that convergence, and the #15254 registry entry names it.

**Four honest states, never a fabricated success:** `unobserved` (today's truth — no wiring injects snapshots yet, and the pane says so plainly rather than rendering an empty inbox that looks loaded), `denied` (an auditable sentence naming the viewer and subject), `degraded` (the owner's reason verbatim), `empty` (explicit, never blank). Rows and a page window appear together or not at all — a denial never fakes a window.

Evidence: L3 (**539 unit specs + a live NL e2e green** — the mounted whitebox proof, not unit mocks) → L3 required (this is a UI leaf with a real render chain and a real delegated-listener path; unit-only would be partial evidence for a view).

## Deltas from ticket

- **The degrade line names no cause** (a repair this PR makes to its own copy). #15269's landed RA-2 gave the adapter fail-closed refusals — unbound request identity, asserted-viewer mismatch, inadmissible namespace subject — and all three arrive as `admission.state: 'unavailable'` beside `capability.state: 'degraded'`, shaped **identically** to a genuine Memory Core outage. The pane cannot distinguish them, so it no longer guesses: "Mailbox source degraded: …" would send an operator to debug Memory Core over a refusal the adapter made about the *viewer*. One neutral word beat adding a fifth pane state — the owner's reason text was always carrying the truth; only the sentence around it was lying.
- **Thread-collapse is seeded explicitly on snapshot replace** rather than derived lazily: a snapshot swap must not inherit the previous snapshot's expansion state, or a thread silently renders expanded for a resident the operator never expanded it for.
- **No dock-liftability** — deliberately out of scope per the ticket; the pane is a tab, and lifting it belongs to the dock grammar follow-up.
- **The e2e drills via `.fm-card-drill`, not `.fm-card-avatar`.** The a11y refactor moved the drill gesture onto a dedicated native Button that owns Enter/Space; the avatar is a handler-less `Image`, so clicking it is a silent no-op. Reported to the swarm separately: the sibling `FleetCockpitDrillNL.spec.mjs` still clicks the avatar and therefore **cannot pass on `dev` today** — it went unseen because the e2e battery does not gate CI. Not fixed here (tracked dev file, needs its own ticket); flagged so it is not mistaken for this PR's collateral.

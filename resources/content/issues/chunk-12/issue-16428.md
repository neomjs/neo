**PR #16496 (`#16495`) is exactly this fix** and imports both symbols directly, bypassing the barrel. It is 11/11 green and MERGEABLE, blocked only on a cross-family review seat.

1. `failed under declared credential scope \`reader\`` — the annotation is prepended to *every* stage failure regardless of class, so a packaging error reads as an auth error. Filed as #16530, fixed in PR #16531.

Structural since the ruleset's 2026-07-17 creation, not a new regression, and repo-security configuration rather than code.

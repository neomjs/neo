# Transfer the frozen Agent OS tracker set to the Brain

## Context

Wave 2.5 produced a frozen 330-ticket baseline. The freeze explicitly permits runway direct sub-work, so this leaf consumes that baseline plus an explicit versioned delta for every sanctioned post-freeze ticket; no allowed ticket becomes an invisible population change. It executes only rows classified for Brain transfer or explicit close-with-pointer and preserves a committed transfer ledger.

#17701 proved the live semantics: transfer creates a replacement node, old URLs redirect, labels map by name, source references become repository-qualified, holding milestones drop, and cross-repository parent/dependency edges survive after projection settles.

## The Problem

Bulk transfer without a frozen baseline, explicit sanctioned-delta ledger, and read-back ledger can strand labels, milestones, relationships, active claims, and close targets. A successful command is not the continuity proof.

## The Architectural Reality

- Brain repo has issues enabled, default `dev`, label taxonomy, and a green relationship-bearing canary.
- Transfers preserve semantic continuity via source→destination mapping plus redirect, not node-ID stability.
- Active PR/lane ownership must be dispositioned before its ticket moves.
- Within the tracker batch, this migration issue transfers after every other Brain-classified issue; this does not order the source/deployment receive leaves, while ledger completion still blocks #17791.

## The Fix

Consume the Wave-2.5 baseline, sanctioned-delta ledger, and cut manifest; transfer the exact Brain-classified set in an operator-visible batch, close non-transferable rows with destination pointers, stabilize and verify every relationship, and commit a deterministic source→destination tracker ledger in the Brain. Within that tracker batch, transfer issue #17790 itself after every other Brain-classified issue so its final Brain-repo ledger PR can resolve the destination issue.

## Out of Scope

## Avoided Traps

- **Node-ID stability assumption:** live canary disproved it.
- **Hash equality as semantic equality:** GitHub qualifies source refs.
- **Green CLI exit as proof:** no post-state.
- **Transfer active work silently:** breaks ownership and close targets.
- **Second canary disguised as bulk:** the baseline is already measured; each sanctioned delta must be classified rather than re-probing transfer semantics.

Chat-Creation — the Keeper Flow

design SSOT · #14645 · apps/agentos module

A stranger types an intent and gets a live app in its own window. chat → "build me a neo grid" → a docked peer panel → drag to its own OS window → use / share. This surface is the impedance-match wedge — legible to someone who never read a line of Neo code. The pipeline that runs behind it (#14655 intake route · #14656 instance registry) is a peer's lane; this artifact fixes what the human sees and touches.

The five states — the SSOT owns these; view leaves bind them

empty

Describe an app to build…

The invitation. A single affordance, no toolbars, no menus. The whole surface says "start here."

composing

build me a grid of the fleet's open PRs
blueprint · Grid · store: pulls · cols: title, author, state

Intent typed; the blueprint is previewed, not committed. The human can refine words or the blueprint before anything runs.

generating

materializing Grid…
cancellable · route #14655 → registry #14656

The blueprint runs the intake route. Progress is honest and interruptible — never a spinner that lies about being stuck.

materialized

Fleet PRs · Grid ↗ window
live docked panel · a first-class instance

The app is alive as a docked peer panel and usable immediately. The promotion affordance (→ own window) is present the moment it exists.

error

blueprint blocked at the safety gate · not built
edit the intent, or view why ↗

Generation failed, or the safety gate refused the blueprint. Always recoverable — edit and retry, never a dead-end, always a reason.

Draw-vs-delegate — the boundary so leaves don't collide

This SSOT owns

  • The creation-surface IA — the empty invitation, where the input lives, how the blueprint preview reads.
  • The interaction model — say → preview → generate → materialize → promote.
  • The five states above, and every transition between them.
  • The promotion affordance — panel → its own OS window on the shared heap.

The pipeline leaves own

  • Intake → blueprint route — #14655 (Mnemosyne).
  • Created-instance registry — #14656: live widgets as first-class records.
  • NL wiring & app-lifecycle — the generation engine behind state 03.
  • The safety contract — #14644 constrained-blueprint gate (see below).

Non-view leaves are buildable now against this contract; only the view tranche waits on the rendered artifact.

notAuthority — the surface proposes, the gate disposes

The chat and its blueprint preview are provisional. They never bypass the constrained-blueprint safety gate (#14644) — the gate is the authority, not the conversation.
This is the #14548 firewall applied to creation: a persuasive intent must not become a live app by persuasion alone. What the human types is a request; what the gate passes is what runs. The error state exists precisely so a refused blueprint reads as a boundary, not a failure of the person.

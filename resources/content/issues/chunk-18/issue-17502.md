# Record the C′ AgentOS extraction topology

## Context

Epic #17500 graduates [D#17489](https://github.com/orgs/neomjs/discussions/17489) into a one-week first-wave AgentOS extraction. The converged C′ shape is architectural authority, but it is not yet recorded in the durable Decision Record series.

ADR 0039 establishes the Brain-internal Cloud/Host-Edge executable boundary inside today's repository. The corrected C′ fold realizes that boundary as package topology in one new repository whose name remains unresolved: the repository root is the Host-Edge package, `cloud/` is an independent nested package, npm workspaces are forbidden, and a pure `shared/` package is conditional on inventory proof.

This is a one-PR leaf: it records the decision and its revalidation/retirement conditions. It moves no runtime code.

## The Problem

Without an ADR, the extraction's load-bearing decisions remain distributed across a long Discussion and Epic body:

- why one repository wins the first wave and why its concrete name requires a separate registry/in-market disposition;
- why root Host Edge and nested Cloud require independent package/install roots with no npm workspaces;
- why package omission is not isolation while workspace hoisting can resolve Cloud dependencies;
- why AgentOS→published Engine is the only dependency direction;
- why runtime root and target checkout root are separate authorities;
- why apps and published `learn/agentos` content stay Engine in wave one;
- which pre-move proofs and cutover gates block relocation;
- why no historical `neomjs/neo` SHA changes.

A later migration PR could otherwise choose a locally convenient workspace, root script, or cwd fallback and still appear consistent with one fragment of the conversation.

## The Architectural Reality

- ADR 0039 owns current Cloud/Host-Edge executable-closure semantics and the paired static/runtime proof requirement.
- D#17489 correction `DC_kwDODSospM4BFFq_` owns the Edge-root / nested-Cloud / no-workspaces fold and the amended first-blocking-leaves timing.
- ADR 0019 owns AiConfig as the reactive SSOT; realm disposition may move config files but may not create second config authorities.
- Fleet's existing workspace provisioning already separates installed `mainCheckout` from target `repoPath`; C′ promotes these to `agentosRuntimeRoot` and `targetRepoRoot`.
- The repository name is not architectural identity: “Agent OS” remains the subsystem term, while the concrete repository name stays unresolved until the naming sweep.
- `scriptPlaneClosure.mjs`, the ADR 0039 denial witnesses, package manifests, and Fleet-managed MCP descriptors are existing primitives; the missing authority is their common plane-owned population.
- `learn/agentos` has Engine Portal/SEO/tree/source consumers and remains Engine in wave one.
- D#17247 remains the long-term topology authority and is not narrowed by this decision.

## The Fix

Add `learn/agentos/decisions/0040-agentos-extraction-topology.md` as the durable record of C′.

The ADR will record:

- resolved repository name plus the Edge-root / nested-Cloud / no-workspaces topology;
- first-wave custody and explicit exclusions;
- dependency direction and Engine package contract;
- plane membership, isolated Edge resolution, static closure, runtime denial, Cloud positive control, and computed-import disposition;
- conditional `shared/` admission: pure, driver-free, capability-free, and inventory-proven—or absent;
- runtime-root versus target-root authority and fail-loud target binding;
- criteria 2/3's amended timing: inventory/membership reconciliation and the temporary paired-gate exercise are the first two blocking Epic proofs and both precede every relocation leaf;
- issue-transfer canary, label provisioning, cut window, and in-flight-lane ledger;
- migration provenance with no second Engine history rewrite;
- relationship to ADR 0039, ADR 0019, Epic #17500, D#17489, and D#17247;
- retirement and revalidation triggers.

Update ADR 0039's relationship surface only as needed to point forward to ADR 0040; do not rewrite ADR 0039's already-shipped two-plane decision.

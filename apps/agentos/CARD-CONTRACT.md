# Fleet Manager Cockpit — AgentCard Contract (#14605)

The single citable contract for what an agent card renders, from which wire fields, under which render rules. Consumers: the AgentCard implementation (`#14598` — its spec suite maps 1:1 to the **mapped** section of the conformance checklist below; the evolved-D additions are listed separately and now carry a recorded witness per row), the detail header (`#14608`), and every surface that renders a resident at card grain. The card belongs to the **fleet-manager module of this one harness app** (operator veto on `#14577`: FM is a module of `apps/agentos`, never a sibling app). Sources of authority: the design SSOT ([`fleet-manager-cockpit-plan.html`](./design/fleet-manager-cockpit-plan.html), `#14512`) · the cockpit DTO ([`ai/services/fleet/fleetCockpitStatus.mjs`](../../ai/services/fleet/fleetCockpitStatus.mjs), merged) · ADR 0032 ([`learn/agentos/decisions/0032-institution-cockpit-render-model.md`](../../learn/agentos/decisions/0032-institution-cockpit-render-model.md), Accepted) · ADR 0029 §2.6 (cards are **layout-blind**: ordinary component lifecycle + config updates only; no layout-event consumption).

There is no dedicated drill control — no `▸`, no expander, and no `Button` wrapping the display name. The retired drill served a principle — *never advertise interactivity a node does not have* — and it is now served by the **behaviour** rather than by restriction: the item genuinely is the target. `Enter` selects the focused row via `AgentOS.view.fleet.roster.SelectionModel.onKeyDownEnter`; item focus and arrow movement belong to the **Navigator addon** (the base list contract), not to the selection model; selection drives the detail reveal. **Lifecycle carve-out, enforced rather than intended:** `SelectionModel.onListClick` returns early when the delegated click path reaches `fm-card-control-verbs` before the item, so operating toggle · restart never re-targets selection — without it every control press would relocate the detail surface and the memories target. ⚠️ **The ACCESSIBLE semantics do not yet match that behaviour, and this row must not claim they do.** `Neo.list.Base` renders the item as `li` (`itemTagName`, `:97`) and emits `aria-selected` unconditionally (`:504`), but attaches a role only when `itemRole` is truthy (`:516-518`) — and `itemRole` defaults to `null` (`:183`) with no roster override. WAI-ARIA 1.2 supports `aria-selected` on `gridcell` · `option` · `row` · `tab`, **not** on `listitem`, so today the state rides a role that cannot carry it. The emitted attribute is evidence of intent, never of conformance | **selection itself has no degrade branch** — an always-rendered item is always selectable, and this row must not invent an absent-detail or unauthorized branch for it. The two real branches live elsewhere and are stated where they degrade: the detail surface owns what it renders for a row it cannot resolve, and the **Control status** row owns `kind === 'unauthorized'` disabling the verbs. A verb disabled there still leaves the item selectable |

| **Control verbs** (in flow) | (behavior: `#14611`) | **actions-in-flow, not a slot** (#15536): toggle + restart render as light proportional icons inside the head row **at every card width — no hidden overflow, no kebab**. Toggle's icon derives from state (`off` → play, else stop); restart is meaningful only while running | unauthorized → disabled-with-reason via the control-status line, never hidden |
| **Control status** (one line, below the verbs) | `pendingAction` / `controlReason` as **`{action, kind, reason}`** — the producer-required shape, all three fields | `hidden` unless a pending action or a reason exists. **Pending takes visual priority over a prior reason**, so a new attempt never displays a stale failure. Two reason branches, both keyed on `kind`: `timeout` renders `<action>… stale — no response`; every other kind renders `⚠ <kind>: <reason>`. `kind === 'unauthorized'` additionally disables the verbs | neither present → hidden. **No missing-field fallback exists and none may be assumed:** `kind` is read unguarded, so a reason lacking it would render `⚠ undefined: …`. Supplying the full shape is the producer's contract, not the card's to repair |
| **Source strip** (foot, one line) | `summarizeFleetSources` → `{level, text, ariaLabel}` | **ONE honest word-line, a pure `role=status`** — replaces the former PR-ref/timestamp foot meta. `fm-strip-<level>` colours the `::before` dot only; the word carries the meaning, so the strip stays legible with colour removed. `text` is a controlled literal from the summariser, never adapter prose — and it renders as an **inert `text` node, never `html`** (#15536): the literal is closed by construction (a frozen label map over a hardcoded key order, with adapter `source` strings read only for the expected-producer comparison), so the SINK is what keeps that unforgettable rather than a property the summariser must remember forever — the same discipline the lane line carries, and the ruling the cockpit spine-banner already landed | the summariser always yields a level and a word — there is no empty strip state; unknown sources summarise to their own honest level |

## Identity rules (the ADR 0032 bindings, restated once for card claimants)

1. The card keys on the **durable id** (`rows[n].id`) — never on name, engine, or family. Any of those changing re-renders the SAME card instance (conformance fixtures below).
2. **No role-typing anywhere** — the card renders states and trails, never castes (§2.3.1).
3. A NEW resident renders with **full affordances from the first deed** (emergence-parity, §2.3.7) — no reduced "young agent" card.
4. Cards are **layout-blind** (ADR 0029 §2.6): no layout-event consumption; pop-out/reparent arrives as ordinary lifecycle, and state carries through (reparent-never-destroyed is landed-normative).

## Conformance checklist — mapped 1:1 to the `#14598` spec suite

- [ ] `key-is-id`: rename / engine-tag change / family rebind each re-render in place — instance id stable across all three.
- [ ] `state-honesty`: a `not-wired` runtime source renders the off-token + marker **for an explicit `off` row**; a not-wired row with any other state renders `unobserved` (participation truth kept, session truth unclaimed); no fixture path renders placeholder-as-fact.
- [ ] `name-fallback`: the DTO's fallback chain renders at every step; null-everything renders the mono id.
- [ ] `family-neutral`: unknown family renders the neutral rail + badge.
- [ ] `emergence-parity`: a first-deed resident fixture renders every card affordance.
- [ ] `layout-blind`: the card's spec imports no layout/dock event surface (lint-assertable).
- [ ] `tokens-only`: zero literal colors/fonts (greppable against `--fm-*`).
- [ ] `state-text-present` (#15512): the card renders the state as text (`stateLabel(displayState)`) beside the dot — legible with colour removed (WCAG 1.4.1); the word is text-safe `--fm-ink-dim`, the dot carries the hue, and an unrecognized state passes through as its literal word.

### Evolved-D anatomy conformance — witnessed (#15536)

The six entries the recompose introduced, each now carrying its witness. **Reading spec titles is the audit; grepping slugs is not** — the pass that mapped these found that NO conformance slug on this page appeared in any `test/` file, including the mapped rows above, because the assertions carry prose titles (`key-is-id` is witnessed as "never a re-key"). A slug grep would have reported false gaps. Every slug below is now greppable: the four specs added here are slug-titled, and the two pre-existing witnesses carry the slug in a comment, so `git grep <slug> -- test/` resolves every row.

`unit` = `test/playwright/unit/apps/agentos/view/fleet/roster/card/container.spec.mjs` · `grid` = `…/fleetGrid.spec.mjs` · `e2e` = `test/playwright/e2e/agentos/AgentCardSynthesisRenderNL.spec.mjs`

- [x] `avatar-persists` (#15536) — **unit**: a null `avatarUrl` keeps the slot mounted and visible with its `alt` retained; no lifecycle state hides the face. **e2e**: goldens render the avatar at 294 / 360 / 720 px in both themes. Width persistence is a `@container` fact and is golden-borne by design; the unit owns the data-driven half only.
- [x] `lane-elision-distinguishes` (#15536) — **unit**: the two `control-plane…` fixtures the e2e also renders collapse to an IDENTICAL head while their preserved tails differ, each an inert text node with no `title` fallback. The goldens catch a visual regression; the unit owns the semantic claim a regenerated baseline could otherwise bless away.
- [x] `lane-is-text-node` — **unit** + **grid**: every lane fragment asserted through `vdom.cn[n].text`; the lane string is remote fleet data and Neo's `html` is `innerHTML`.
- [x] `verbs-in-flow` (#15536) — **unit**: the rail holds exactly two native `button`s, and a visible power verb survives every lifecycle state with its glyph following state. **e2e**: asserts `hasMenu === false` ("controls are inline, not hidden") plus the 44 px narrow / 32 px regular action size per width scope — the width half is genuinely asserted, not merely snapshotted.
- [x] `control-status-priority` — **unit**: a `controlReason` renders, then a new `pendingAction` REPLACES it, so no stale failure survives a new attempt.
- [x] `strip-is-status` (#15536) — **unit**: `role=status` reaches the vdom root; the word is an inert `text` node carrying no `html` key at construct or across updates; the node is non-interactive with no disclosure affordance; the word changes with the level so colour is never the sole carrier; and a hostile adapter `source` literal fails the row closed without reaching the word or the `aria-label`.

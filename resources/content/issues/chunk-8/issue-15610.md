# Wire advisory consumers to SeatEvidenceCapabilities.md (+ freshness obligation)

## Context

Author-owned follow-up from Vega's APPROVE+FOLLOW-UP review of PR `#15609` (`PRR_kwDODSospM8AAAABGkLmJA`, merged): the seat-capability doc names `pr-review` / `whitebox-e2e` / QT-matrix as advisory consumers that "SHOULD consult" it, but wires none of them — a routing convention nobody is routed to never fires. Plus one maintainer-polish item: the `@neo-opus-*` row lacks the shared-host grain note the Kimi/GPT rows carry.

Live latest-open sweep: checked latest 20 open issues at 2026-07-20T14:20Z — no equivalent. A2A in-flight sweep: no competing claim.

## The Problem

1. **Latent integration gap:** `learn/agentos/process/SeatEvidenceCapabilities.md` exists, but no consumer payload references it. An agent routing visual/headed work tomorrow has no mechanical pointer to the doc — the convention depends on ambient memory, which is exactly the tribal-knowledge failure mode `#15592` was filed to retire.
2. **Freshness obligation unwired:** the doc's records carry `observedAt` + `revalidationTrigger` (stale renders as `unknown`), but markdown cannot auto-render staleness — consumers must be told to check freshness, not just the state cell.
3. **Grain ambiguity:** the `@neo-opus-*` row aggregates per-family without a host note; the recorded negative is harness-scoped (in-app browser wedge), not host-scoped — the grain must say so or readers generalize a harness ceiling to a host ceiling.

## The Fix

1. **Skill pointers (minimal footprint, progressive disclosure):** add a short pointer to the doc in the `pr-review` and `whitebox-e2e` skill payloads (reference files, not the SKILL.md routers), covering: consult `SeatEvidenceCapabilities.md` before routing visual-render / headed-harness / matrix evidence work; honor the freshness obligation (`observedAt` + `revalidationTrigger`; stale = `unknown`); records are advisory (a `negative` is an expectation, not a ban; counter-receipts retire ceilings).
2. **Grain clarification:** mark the `@neo-opus-*` row's grain as shared macOS host + harness-scoped ceiling.
3. **QT-matrix consumer:** notify the `#15243`-line owner (A2A) that the doc exists — the matrix flow is a live lane, wired by notification rather than edit.

`none` — pointers + doc clarification; no behavior change. Skill-payload edits follow create-skill progressive-disclosure discipline (reference files, not routers).

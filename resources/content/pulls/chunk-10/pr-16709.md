Resolves #16707

The per-seat session-cost reporter: one `ai:` CLI aggregating both harness-local token ledgers (kimi-code `wire.jsonl` usage records; opencode `message` token rows) into a per-seat per-day table — calls, fresh input, cache read/write, output, raw total, an estimated needle share, and the `gaps > warmWindow` incidence column — plus the capped/uncapped ablation readout behind one flag. The aggregation core descends from the 08-08 drain-forensics seat scripts, hardened into a fixture-validated CLI. Deliberately graphless: no AiConfig import (the diagnostics-script boundary mirrors `ai/daemons/wake/`).

Evidence: L1 (unit suite — fixture-driven aggregation/dedupe/gap-incidence/render/CLI assertions) plus a live-ledger validation receipt on the operator machine (below) → L1 required (the ticket's ACs are CLI-level). Residual: none [#16707]. AC-2 (the wake-carried digest line) stayed with @neo-kimi-phoebe per her handoff comment.

## Deltas from ticket

- The fixtures are committed JSON/JSONL (a wire fixture + a rows fixture); the sqlite reader loads better-sqlite3 lazily only for live-db runs — the base install tier has no native compile, so fixture runs never load it. The AC's "fixture db" intent (no live-machine dependency in CI) is preserved; the db-reader path shares its row parsing with the fixture path by construction.
- AC-1's "reproduces the table" is asserted exactly on the needle-bearing token columns; fixture call counts are asserted against the fixture's own truth (documented in the spec header). The live-ledger run below is the end-to-end validation receipt.
- AC-2 (the wake digest line) is NOT in this PR — Phoebe carries it as a Refs micro-PR after #16705 merges (her handoff comment, 14:43Z).

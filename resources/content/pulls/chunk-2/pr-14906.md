Resolves #14654

Ships line D1 of the auto-hide arc as `Neo.dashboard.DockRail`: the edge-rail vdom skeleton that landed with the projection slice (#13770) becomes a real affordance — labeled, policy-honest rail tabs that restore their item through the dock-zone executor. The rail is a `container.Base` composing real `button.Base` children: clicks ride the button `handler` contract (zero manual DOM listeners), each button carries its `dockItemId` on the instance, and model flips reconcile the button set in place — surviving tabs keep their live component instance. The adapter projects `module: DockRail` per railed edge (mirroring the `DockSplitter` affordance idiom, including reducer-callback threading), and `createRailTab` projects metadata (`dockEdge`, `dockItemId`, `restorable`, `title`) — the pane stays blind to being railed, and a tab whose restore the model would reject (`pinnable` flipped after railing) renders as a genuinely disabled button instead of emitting a doomed operation.

Evidence: L2 (unit contract specs — component + adapter projection, 166/166 dashboard suite green) → L2 required (close-target ACs are spec/diff-checkable; no runtime-verify AC). Residual: none — the browser-visual language is the F-tranche close-target (#14638), which consumes the styling hooks shipped here.

## AC map

- **Rail renders from model state only** → the adapter projects rails exclusively from committed `autoHidden` truth; the component builds buttons from `railItems` metadata; reveal/open state does not exist in this slice.
- **Restore rides the executor; policy hints respected** → button handler → `{operation: 'setItemAutoHidden', autoHidden: false, itemId}` through the `applyDockZoneOperation` callback or a local `DockZoneModel.applyOperation()` — the exact `DockSplitter.commitResizeSplit()` contract, no parallel path. A non-restorable tab is a disabled `button.Base` and rejects locally (specs: callback, local-commit, executor-rejection, policy incl. live re-enable).
- **Reactive without remount** → `reconcileTabs()` preserves surviving button INSTANCES across model flips (spec asserts reference identity through add/update/remove cycles) — object permanence proper, not vdom-diff approximation.
- **Unit specs incl. multi-edge + rapid-toggle** → multi-edge grouping (left+right membership) + rapid-toggle round-trip through the real executor (adapter suite).
- **Cross-family review** → re-requested post-CI-green on the reworked head.

## Evolution

- **Composition pivot (operator review, pre-merge):** the first cut hand-rolled `tag: 'button'` vdom nodes plus manual click delegation inside `component.Base` — raw-DOM synthesis that ignored the Body's composition model. Rebuilt on `container.Base` + `button.Base` children: the button `handler` config IS the click contract ("Shortcut for domListeners={click:handler}"), layout direction comes from the container layout, and the tab-id→item-id bookkeeping map disappeared entirely because instances carry their own identity. The no-remount AC got strictly stronger in the process (instance preservation, not node diffing).
- **DOM `data-*` attributes dropped:** `data` is a vdom-node feature, not a component config — the first cut's dataset hooks were inert on real buttons. Instance-level `dockItemId` is the better whitebox seam anyway (Neural Link `find_instances` / instance inspection rather than dataset scraping).

## Deltas from ticket

- **The rig targets self-possession, not a disposable launch.** Both second-instance paths were measured dead: OpenCode holds a single-instance lock (spawned binary and `open -n --args --user-data-dir=…` alike exit without a window). The honest remainder drives the authoring seat's OWN shell — exactly the harness shape the gate protects — with disturbance confined to one composer field (typed, asserted, cleared) plus a transient About panel. The avoided trap honored is driving a PEER'S seat.
- **Two AppleScript coupling traps discovered and documented in-rig:** (1) `… whose unix id is N` binds to the DIRECT object, so window queries against a pid-filtered process die with -1728 unless the process is pre-bound via `set targetProc` (production's `resolveTargetProcessLines` already uses the correct shape); (2) repeated `-e` flags compile as separate units here, so the rig joins fragments into one document.
- **Phase B redelivery polls the adapter directly rather than re-driving receiver park/reschedule** — that half is L2-covered by the existing spec and out of the leaf's scope; isolating the adapter-level temporal fact keeps a rig failure attributable.

## Next: Engine 13.2 — A Runtime That Ships From Several Repositories

v13.1 made the institution safe to leave running. Since then the organism split into sibling repositories, and **13.2 is the engine's first release after that split**: the multi-threaded runtime, its dock layouts and its flagship Workstation ship from [neomjs/neo](https://github.com/neomjs/neo) on their own cadence, while the Agent OS and the Fleet Manager release on theirs. The release gate is behaviour we can observe:

> **The engine's site deploys from the published `neo.mjs` package with the portal and the docking demos current; a second Workstation window never kills the first; the Knowledge Base the institution steers by reads the current corpus, so the Dream Pipeline and the Golden Path forecast again; the docking demos are public, animated and e2e-tested; and the release notes tell the engine's story, not the organism's.**

This section names the gate and the load-bearing path, not a frozen checklist. [Milestone #9](https://github.com/neomjs/neo/milestone/9) is the tracking milestone; its linked items are the full set.

**Three release lines, in order.** The engine is the only repository that has cut a release (13.1.0); the skills package already ships on its own npm cadence; the Brain releases as container images; the Institution pins a `dev` engine commit today. So there is no org release — there are three lines, each with its own gate and its own notes, sequenced because the later ones consume the earlier:

| Line | Repository | Gate | Notes |
|---|---|---|---|
| **Engine 13.2** | [neomjs/neo](https://github.com/neomjs/neo) | the sentence above | the engine's own |
| **Brain runtime** | [neomjs/neo-agent-brain](https://github.com/neomjs/neo-agent-brain) | the Brain-built images ([neomjs/neo-agent-brain#253](https://github.com/neomjs/neo-agent-brain/issues/253)) run the current Knowledge Base tenant ([neomjs/neo-agent-brain#402](https://github.com/neomjs/neo-agent-brain/issues/402)); Golden Path v2 ([neomjs/neo-agent-brain#122](https://github.com/neomjs/neo-agent-brain/issues/122)) is its first cornerstone after that cut | the runtime's own |

The other repositories ride these lines: [neomjs/neo-agent-skills](https://github.com/neomjs/neo-agent-skills) ships 0.1.x as the shared working discipline; [neomjs/devindex](https://github.com/neomjs/devindex) is its own workspace on the published engine and deploys under whatever topology [D#19050](https://github.com/neomjs/neo/discussions/19050) settles; [neomjs/github-content-sync](https://github.com/neomjs/github-content-sync) publishes the organisation's conversation corpus hourly and has no release; [neomjs/pages](https://github.com/neomjs/pages) is the deployment target, not a product. Where a repository keeps its own next-release section, that section governs its line; this file governs the engine's.

**How it runs.** Ordering follows the consumption chain: the image cut unblocks the Knowledge Base tenant, which the Dream Pipeline, the Fleet Manager feed and the portal indexes all consume; the deploy decision (D#19050) and the content decision (D#19051) are text and proceed in parallel; the crash fix lands inside 13.2 while the heap boundary waits for its open questions. Cadence: steady state is roughly 100–150 merged PRs per release, and 13.2 is already past that on the milestone, so no further cornerstone is added — new work attaches under an existing epic or waits for the next line. Any peer claims subs; the steward owns the outcome and closes the epic.

Resolves #14668

Ships line B5 — the changed-topology restore reconciler — as `Neo.dashboard.DockTopologyReconciler`: a pure static module mapping captured workspace slots onto live windows by id-free shape affinity, composing the landed per-window restore, and reporting everything it cannot cover in both directions. This is the leaf the same-topology planner's `topology-fingerprint-mismatch` deferral explicitly reserved ("the cross-topology leaf owns that path"). Mapping: Jaccard overlap of item catalogs → node-type-multiset structural tie-breaker → stable live order, greedy in captured order — deterministic by construction. Per mapped pair: identical shape fingerprint restores incrementally through `DockRestorePlanner.restoreToward()` (zero duplicated restore logic); changed shape adopts the captured document wholesale with every live-only item reported in `displaced`. Uncovered captured content returns reason-classed (`no-live-window` / `unmapped-slot` / `validation-failed`); the validation boundary fails the ENTIRE restore closed (no partial restore); no window-creation path exists anywhere in the module and excess live windows keep reference-identical documents.

Evidence: L2 (205/205 dashboard unit suite; 9 contract specs pin every AC clause incl. the cycle-1 additions: greedy-trap, exact-tie permutation, envelope negatives, global uniqueness, deferral pass-through, apply-error) → L2 required (all close-target ACs are spec/diff-checkable pure logic; the ticket's own Out-of-Scope excludes UI rendering — Demo-B G4 + B7 consume the result shape). Residual: none.

## AC map

- **Unrestored carries reason classes; NOTHING silently drops** → conservation invariant asserted in EVERY spec: restored + unrestored ids === captured ids exactly. Plus the honest extension: `displaced` reports live-side items absent from an adopted document — silent drops are banned in both directions.
- **No window creation in v1** → no spawning surface exists in the module (review-checkable); grown-topology spec pins excess windows as reference-identical untouched documents.

Resolves #13845

Refs #13835 (parent — the full tri-state digest-state contract; this PR delivers its **stop-re-serve kernel** leaf, split out per a close-target review so it does not over-claim #13835's broader taxonomy/terminal contract).

The operator-escalated load-reducer for the live gemma4 saturation (graduated from Discussion #12839). Today a session that cannot be digested is never marked `graphDigested`, so `DreamService.findUndigestedSessions` **re-serves it every cycle**, the extractor re-attempts and re-fails, and each cycle re-pays the per-session pre-check on the saturated local model — forever. This bounds that bleed.

## What this does

Replaces the binary `graphDigested` digest-state with a tri-state contract, **bounding the re-serve**:

- On digest **failure** (extractor returns `null` OR memory-ingestion errors), `processUndigestedSessions` now tracks the attempt: persists `digestState` / `digestAttempts` / `deferReason` to the session metadata. Once `digestAttempts` reaches `MAX_DIGEST_ATTEMPTS` (3), the session is marked **`deferred`**.
- `findUndigestedSessions` (via `addUndigestedRowsFromBatch`) **excludes `deferred` sessions** from the steady cadence — the load-reduction lever: the orchestrator stops re-serving (and re-paying the pre-check on) a session that cannot clear. Below the threshold the session stays `undigested` (re-served), so genuinely-transient failures still get a few retries.
- `deferReason` records WHY for the honest consolidation-gap surface and a future deep-digest lane: `ingestion-failure`, `skip-over-band` (payload over the safe band), or `under-band-choke` (under the band but the model returned empty — @neo-opus-grace's live finding).
- On **success**, `digestState: 'digested'` is set alongside `graphDigested: true`.
- **Back-compat:** `graphDigested` is preserved on success and never set on failure, and `findUndigestedSessions` falls back to the `graphDigested !== true` check when `digestState` is absent — so a consumer (or a Chroma row) that predates `digestState` still sees an un-digested (never a falsely-digested) session, and `ChromaManager` Axis-A counts are unaffected for digested rows.

Evidence: L2 (focused unit specs for the candidate-scan exclusion + the bounded-marking failure path) → L2 required (digest-state contract + scheduling consumer, fully unit-covered). Residual: the remaining #13835 ACs — the 4th/5th `deferReason` (`wall-clock-timeout`, `schema-failure`; need the extractor's return-contract), the terminal `undigestible` state, AiConfig-backed `N`, and the `SemanticGraphExtractor` choke-vs-`context-overflow` relabel — **stay open in the #13835 parent**. This PR fully delivers the **#13845** kernel leaf, not #13835's full contract.

## Deltas from ticket

1. **Queued · next is LIVE, not sample.** The sketch (§4) listed "Schedule (next runs): no verb yet — D#11857". Intake falsified that: the deployment snapshot already carries schedule truth — `tenantRepoSync.repos[].nextDueAt` / `due`, `maintenance.retry.nextAttemptAtMs`, and the sweep's `task.running` / `lastCompletion` — so queued rows bind to it. The honest sample survives only on the cold spine (no snapshot, or a transport-level fallback with no source axes), never beside live rows.
2. **The Knowledge Base ingestion verb is bound in-process mode only.** The plane client proves identity against the Memory Core plane (`list_permissions`) and holds no Knowledge Base session, so plane mode leaves `getIngestionProgress` out and the source answers that axis as the typed `unwired` state — which does not degrade the envelope; the snapshot carries the deployment's real ingestion lane in both modes.
3. **Row grammar renders the state word AND the optional progress**, not one-or-the-other as sketched: the word is the always-present text channel, the bar is additive.
4. **The cockpit drives the read** at boot, on every liveness tick (with its own in-flight cap) and on reconnect, instead of intent-only: a WHAT surface that says "not observed yet — click Refresh" is not mission control. The pane still never reads on its own (sibling contract).
5. **Transport-cold vs source-cold are told apart structurally** (no source axes ⇒ the cockpit never reached the source): transport-cold keeps the labeled sample (the Activity stream's fail-closed-never-blank convention); source-cold renders the honest empty lines under the reason.
6. `.claude/launch.json` gains a `cockpit-live` preview configuration (`npm run cockpit:live`) so a plane-bound headed receipt is one click for the next peer.
7. **Review round 1 (Euclid) — the reducer now obeys its producers, and the ticket carries the T3 Contract Ledger it lacked.** The REM "fresh cycle ⇒ running" branch is gone: `HealthService.buildRemPipelineState` projects completed-cycle summaries (`runId`, `wallClockMs` — a duration, overflow facts, `outcome`) with no instant and no active flag, so the REM row is always the queue fact under the word `backlog`, and `axisErrors` on a count axis answers the typed `rem-axis-error` instead of a wired zero. The deployment reader's `stale` / `degraded` envelopes (`ok:false` with the snapshot RETAINED) keep their rows under their own word; the real `unavailable` envelope fails closed with the producer reason. A failed tenant-sync completion is stamped by `lastErrorAt`, a skipped sweep by `lastRunAt` — never by the preserved older `lastSuccessAt`. The first-cut fixtures had modeled fields the producers do not emit; every REM/deployment fixture is now producer-shaped and the ledger names each source of authority.

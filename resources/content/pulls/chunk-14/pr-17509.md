Resolves #17311

The operator's first-send friction, fixed at both controls: a selected recipient is now REMOVABLE — click its row again (a new opt-in `toggleOnClick` on `Neo.selection.ListModel`, default false, so no existing consumer changes) or activate the action-named close button on its chip. The current selection renders through `RecipientChipList`, a projection over the picker's OWN Store instance (shared, never owned) drawing the selected subset of the SAME records — a roster rename or removal after selection converges into the chips, the picker rows and the eventual `to` array instead of freezing in a snapshot. The `AGENT:*` broadcast sentinel is DEFINED as exclusive: it and named picks never co-exist; whichever side was newly picked wins. Priority drops the three-item combo for a three-radio group (the whole decision space visible), keeping the shipped `high` default — the ticket's original `normal` line is amended in-body with the AC-7 steering rationale.

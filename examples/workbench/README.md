# Workbench Shared UI Prototypes

`examples/workbench/` holds shared Body-layer UI helpers and prototypes consumed across multiple Neo applications and examples before promotion to public `src/` Engine packages (`CodeView.mjs`, `formatConfig.mjs`, `CommandPalette.mjs`, `CommandActionList.mjs`, and `CommandActionModel.mjs`).

## Command Palette Prototype (`CommandPalette.mjs` & `CommandActionList.mjs`)

`Neo.examples.workbench.CommandPalette` (`ntype: 'workbench-command-palette'`) composes existing Engine primitives across two distinct applications without coupling to either app's state model:

- **Engine primitive composition:**
  - Extends `Neo.dialog.Base` (`modal: true`, `trapFocus: true`, `draggable: false`, `resizable: false`, `closeAction: 'hide'`, `parentId: 'document.body'`), inheriting `.neo-dialog-modal-mask` synchronization, `DomAccess.trapFocus` `Tab` wrapping, `Escape` dismissal, header close routing, and `Dialog#focusOnArrival` onto the search field.
  - Pairs a `Neo.form.field.Text` (`role: 'combobox'`) with `Neo.examples.workbench.CommandActionList` (`extends Neo.list.Base`, `role: 'listbox'`, `itemRole: 'option'`, `itemsFocusable: false`, `keepFocusIndex: true`) via `navigator: {eventSource: queryField.getInputElId(), wrap: true}` (`ComboBox#createPickerComponent` pattern), delegating `ArrowDown`, `ArrowUp`, `Home`, `End`, `Enter`, `aria-activedescendant`, and smooth scroll-into-view to `Neo.main.addon.Navigator` on the Main thread.
- **Palette contract:** Consumers provide eligible labeled actions (`{id, label, group, description, keywords, shortcut, iconCls, available, unavailableReason, managesFocus, handler}`) through `actionProvider({context, palette, windowId})` or `actions`, backed by a `Neo.data.Store` of `Neo.examples.workbench.CommandActionModel` records.
- **Unavailable & empty states:** Empty queries and zero-match filters render explicit messages; available actions sort ahead of unavailable ones (`sorters: [{direction: 'DESC', property: 'available'}]`) while unavailable items remain navigable and clickable (`aria-disabled="true"`, `.neo-is-unavailable`) with an explicit `unavailableReason` pill, announcing refusals through `role="status"` (`aria-live="polite"`) without invoking handlers or dismissing the dialog.

### Consumer Integrations

1. **`apps/workstation` (`Workstation.view.Workspace`, `WorkspaceController`, `TourToolbar`):**
   - Owns `commandPalette_` (`ClassSystemUtil.beforeSetInstance`) on `Workspace` and exposes real arrangement switches (`Operations`, `Planning`), topology reset (`Reset to default`), Group transaction `Undo` / `Redo`, active-window dock pane focus jumps, guided tour `Start` / `Continue`, and `Light mode` / `Dark mode` theme toggles across the main workspace and torn-out popup vessels.
2. **`apps/webdesktop` (`WebDesktop.view.Viewport`, `ViewportController`, `Taskbar`):**
   - Owns `commandPalette_` (`ClassSystemUtil.beforeSetInstance`) on `Viewport` and exposes account sign-in (`stores.accounts`), RBAC permission-gated desktop app launches (`stores.apps` + `desktop.openApp()`), `Permissions` simulation panel toggle, `neo-theme-neo-dark` / `neo-theme-neo-light` theme switching, and `Sign out`.

### Empirical Engine Limits & Graduation Criteria for `src/` Promotion

1. **`Neo.list.Base#useHeaders` vs dynamic action sorting and ARIA listbox semantics:** Enabling `useHeaders: true` on `Neo.list.Base` switches the root VDOM from `<ul>/<li>` to `<dl>/<dt>/<dd>`, forces `scrollIntoViewOnFocus = false`, and expects synthetic `{isHeader: true}` records inside the `Store` — which inflates `store.getCount()` announcements and breaks under `sorters: [{direction: 'DESC', property: 'available'}]` (header rows sort away from their group's actions). Graduating grouped listbox sections to `src/` needs non-record visual section headers or a group-preserving store projection; `CommandActionList` renders `record.group` as an inline option badge instead.
2. **`Neo.list.Base#disabledField` vs discoverable unavailable actions:** `Neo.list.Base` maps `disabledField` to `.neo-disabled` (`pointer-events: none` in `Global.css`) and `nonInteractiveItemCls` (excluded from `Navigator`'s selector and click delegate). When every filtered match is unavailable (e.g. searching `"Undo layout"` before a move, or `"Open Mail"` as Guest), excluding those rows leaves zero navigable options and suppresses refusal announcements. A graduated `src/` command list needs a distinct `ariaDisabledField` / discoverable-disabled mode alongside `disabledField`.
3. **`Neo.dialog.Base#initVnode` offscreen-revert assumption on plain-`<body>` apps:** Without `animateTargetId`, `Dialog#initVnode` reverts `.neo-floating` (`left/top: -10000px`) by writing inline `wrapperStyle.left = 'initial'` and `wrapperStyle.top = 'initial'`. That centers only inside `body.neo-body-viewport` (`display: flex; justify-content: center`); on plain block `<body>` documents (`WebDesktop`, component test hosts), `initial` resolves to `(0, 0)` and inline styles beat stylesheet `left`/`top` rules unless the dialog supplies explicit `wrapperStyle: {left: '50%', top: '...', transform: 'translateX(-50%)'}`.
4. **`Neo.form.field.Base` `KeyNavigation#keyDownEventBubble` inside `Neo.dialog.Base`:** `Field` initializes `keys: {}` with `KeyNavigation#keyDownEventBubble: false`, which stops App-worker `keydown` propagation in `Neo.manager.DomEvent` before `Escape` reaches an enclosing `Dialog`'s `keys: {Escape: 'onKeyDownEscape'}`. Setting `keys: null` on the palette's `TextField` restores native `Dialog` `Escape` dismissal.
5. **Main-thread modifier-chord `preventDefault` (`Neo.main.DomEvents#registerPreventDefaultKeys`):** `DomEvents` keys `preventDefaultKeys` by `(nodeId, event.key)` without modifier predicates (`ctrlKey` / `metaKey` / `shiftKey` / `altKey`). Registering `'k'` would block typing `'k'`, so `Ctrl+K` / `Meta+K` cannot call synchronous Main-thread `event.preventDefault()` against browser address-bar bindings on Windows/Linux without a chord predicate alongside `F1`.
6. **Multi-window `SharedWorker` attachment & post-action focus survival:** Moving a floating `Dialog` across `SharedWorker` windows (`Workstation` popups) requires `await unmount()` before switching `windowId` so `Navigator`, `trapFocus`, and `syncModalMask` rebind in the target window; actions that re-project or unmount the origin control (`Sign in` / `Sign out`, arrangement switches) require an explicit post-settlement `fallbackFocusId` probe rather than departure-time `revertFocusOnDeparture` alone.
7. **Pull-on-open & unbuffered `Neo.list.Base`:** `actionProvider` runs on `open()` (`refreshActions()` updates while open), and `Neo.list.Base` renders all filtered DOM options directly; 1,000+ workspace symbol/file quick-open would pair the same dialog/combobox shell with `Neo.list.Buffered`.

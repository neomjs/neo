## What this leaf holds (all DELIVERED by PR #15350 at `f7b5747e3b`, APPROVED)

The WCAG 2.1 contrast **measurement** over the shipped `fm-*` token layer, both skins, recorded in the drift-proof home:

- The full ink×surface table in `apps/agentos/TOKENS.md`, threshold argued **per usage class from the doc's own Role column** (`--fm-ink-faint` carries meta *text* → 4.5; a state dot is non-text → 3.0), with the maths positive-controlled first (`#000/#fff = 21.00`, `#777/#fff = 4.48`).
- **Two failures recorded** (not fixed — the delta rule makes a value change a design decision): `--fm-ink-faint` fails 4.5:1 on **every** surface in **both** skins (2.64–3.27, **latent** — zero live consumers); `--fm-state-off` fails 3:1 on **four shipped** surfaces (**live** — it is both the off-indicator and `stateToken()`'s unknown-state fallback).
- **A doc correction**: the ink-tier row claimed `--fm-ink-faint` is consumed by *"every view leaf"*. No leaf consumes it.
- **The reduced-motion audit result** (#14619 AC3): the claim holds — the pulse carries no unique signal — **and the mechanism that makes it hold is a WCAG 1.4.1 failure**, recorded in the Motion section.

Independently re-derived by @neo-opus-ada from a separately written luminance function: **3.00 and 2.77 to the digit.**

- **AC1's disposition half**: *"failures fixed or ticketed with design-authority sign-off"* — F1/F2 are token deltas awaiting @neo-opus-grace's ruling.

Needs a mounted whitebox-e2e; a source-grep would be a guard aimed at a filename (#15345's class), and an expected-tab-sequence fixture would pin a layout preset rather than an invariant (dock zones are document-driven via `resolveDockComponentRef`).

## 📋 13.2 in 2 Minutes

**The one line:** the engine's docking truth is now a document, not a widget tree. Interactions only propose semantic operations, and a reducer is the one place that commits them, so layouts can move between windows and survive a reload.

## 🧩 Dock Layouts: built, then rebuilt

### Where it started

npm `neo.mjs@13.1.0` published five files under `src/dashboard/`:
- the generic `Container` and `Panel`;
- three experimental dock foundations: `DockZoneModel.mjs` (1,329 lines), `DockLayoutAdapter.mjs` (572) and `DockSplitter.mjs` (399). The counts come from D#17818's release-boundary census.

July built on that foundation fast:
- **The showcase batch, 07-04 to 07-14:** Neural Link dock tools (#14587), an animated choreography demo (#14589), a perspectives demo with window pop-out (#14590), and whitebox e2e with animation assertions (#14591).
- **The tear-out gesture, 2026-07-18:** it went from G1 to G4 in seven hours (#15444 at 09:49Z, #15480 at 16:50Z). The last subject line reads *"the item comes home"*.

### Why rebuild it

By late August the subsystem was rich and inconsistent. D#17818 and #17836 measured three problems:
- **Resize handles differed by history.** Initial edge-zone bands had no resize handle while split nodes did, so a user's rearranged layout gained affordances the shipped one lacked.
- **Tab selection was lost on resize.** Selecting a non-first tab lived only in the view. The next size commit re-projected the stored document and reactivated the first tab.
- **Four files held most of the package.** The four largest held 6,225 lines, 38.8% of it.

On 2026-08-27 the operator ruled DockLayouts a 13.2 greenfield surface. As recorded in D#17818, the ruling had three parts:
- a hard cut: no migration path, compatibility facade, alias layer, dual schema, deprecation period, or parallel old implementation;
- no planning products;
- no line-count target: delete what the architecture makes unnecessary.

The 13.1 boundary made the hard cut affordable: no published version carried the new system.
- **What 13.1.0 did publish:** the three experimental `Dock*` foundations. The cut removed them without a compatibility layer, so a 13.1 consumer that imported them has to port (see the upgrade path).
- **Consumers:** the system's three consumers were updated in the same cut: the Agent Institution in its own repository, `apps/workstation`, and the `examples/dashboard` family.

### The shape

The state model is [ADR 0029](https://github.com/neomjs/neo/blob/dev/learn/agentos/decisions/0029-docking-design.md):
- the committed dock document and its perspectives are serialisable truth, owned by the App Worker;
- each window's projected configs and affordances are derived from that truth;
- mid-gesture pixels, previews and hover state are runtime-only;
- DOM geometry and physical windows stay on the main thread;
- interactions emit semantic operations, and only the reducer commits them;
- `DragCoordinator` knows nothing about docking, and persistence never accepts a DOM, window or runtime object.

## 🧮 Grid cell editing, rebuilt for the pooled grid

### Where it started

`Neo.grid.plugin.CellEditing` was a 34-line subclass of the Table plugin. It was chosen in 2024 (#6168), before row pooling, cell pooling, multi-body rendering and View-owned focus existed.

At `dev@d688710175` the feature was broken:
- double-click, Enter and F2 mounted no editor;
- the double-click threw;
- the public `examples/grid/cellEditing` rendered no rows.

Two attempts that kept the Table inheritance (PR #17937, PR #18222) were dropped on the operator's boundary: the Grid gets its own implementation.

### The shape

D#17832 settled the design with a spike:
- the Row stays the only projection authority and embeds the session's editor at render time;
- a logical session `{recordId, dataField}` survives both pooling axes, so scrolling neither commits nor cancels an edit.

### Four days, 27 PRs

Epic #18762 ran 2026-09-16 → 09-19. Authors: @neo-fable 10, @neo-opus-ada 7, @neo-opus-grace 5, @neo-opus-vega 4, @neo-gpt 1. Cross-family review came from @neo-gpt and @neo-gpt-emmy.

| Day | Merges | What landed |
|---|---|---|
| 09-16 | 3, the first 3 h 14 min after the epic was filed | the core session projected into pooled cells (#18769); the public example renders again (#18773); a landing update no longer overwrites newer typing (#18798) |
| 09-17 | 0 | the GPT and Fable seats were rate-limited; the epic named their return as its revalidation trigger |
| 09-18 | 15 | an evaluation round on the public example failed 6 of 11 paths; the day's leaves covered pickers, ComboBoxes, Tab, `aria-readonly`, locked bodies, IME and the Grids guide (#18852 … #18935) |
| 09-19 | 9 | a return review ran an independent 120 × 400 pass and found one terminal the leaves had missed, arrows while suspended (#18958); selection-model grids, the runtime `cellEditing` toggle, nested fields and tree columns followed (#18943 … #18983) |

### The lesson

Slice 1's arms were green, but they drove a synthetic text-only fixture. The first real pointer-and-keyboard pass over the public example failed 6 of 11 paths, and 15 leaves followed that afternoon. Green on the happy path was never the claim. Each evaluation round had to be survived.

### Also fixed along the way

The arc surfaced six engine fixes, each filed on its own:
- `promiseUpdate()` settled on the wrong render (#18782);
- a unit spec leaked `DomAccess` (#18776);
- deferred body renders dropped callers' intent (#18942);
- a `forceSelection` ComboBox (#18948);
- unlocking a region's last locked column erased it (#18978);
- a runtime lock change left a stale header class behind (#18986).

### Honest bounds

- **No screen reader was run.** The `aria-readonly` arms read the attribute, not an announcement (#18876).
- **The IME probe is synthetic.** It drives CDP composition events, so a real OS IME is not certified.
- **One bound closed after the epic.** Non-text editors on nested fields, in tree columns and across projection loss were unwitnessed at the epic's close. They were witnessed two hours later (#18987, PR #18991).

# Electron shell skeleton + multi-window join — the #13033 slices 1–2 PR vehicle

## Context

The first runnable PR of #13033's four-slice build plan (Ada's 2026-06-13 intake, executed per its handoff clause — Vega on the Electron-runnable engine; lane-handoff A2A sent 2026-07-10). One-PR-per-ticket discipline: #13033 stays the multi-slice leaf; this ticket carries slices 1–2 so the PR has a resolvable close target. ADR 0034 (merged) is the upstream contract.

## Scope (Ada's slices 1–2, verbatim intent)

1. **Shell skeleton** — top-level packaging root (`harness/` (operator-named 2026-07-10: the ROLE — the Agent Harness made installable — not the vessel technology), own `package.json`, pinned Electron) + main entry booting ONE `BrowserWindow` that serves the harness app over the ADR 0034 privileged `app://` origin (repo root as document root), with the §2.3 fail-closed posture: same-origin window allowlist, off-origin navigation denial, deny-by-default permissions, capability preload.
2. **Multi-window join** — a renderer-initiated `window.open` popup materializes through `setWindowOpenHandler` and joins the SAME shared workers (observable: the popup's Neo viewport id CONTINUES the instance sequence handed out by the one App worker; its network trace fetches no second worker).

**Operator decision folded in (2026-07-10):** the harness window loads the zero-build SOURCE app (dev mode) — the Neural Link's possession depth (`inspect_class` / `get_method_source` / `patch_code`) requires real source ESM; minified `dist` output destroys it. Recorded as an ADR 0034 §2.6 amendment in the same PR.

## Acceptance Criteria

- [ ] `cd harness && npm install && npm start` boots the harness window serving the dev-mode agentos app on `app://`.
- [ ] `npm run smoke` self-verifies: both windows mount (>10 Neo nodes), the popup materializes via the fail-closed handler, shared-heap evidence recorded (viewport-id sequence continuation), JSON verdict + exit code.
- [ ] ADR 0034 §2.6 amended with the dev-mode decision (operator, 2026-07-10).
- [ ] `learn/benefits/ArchitectureOverview.md` Structural Inventory row for `harness/` (the #13033 intake's Blocking AC).
- [ ] Dev-loop isolation: no `src/`/`apps/` file gains a shell dependency (Ada's slice-4 assertion holds trivially — the diff touches no source hemisphere).

## Out of Scope

Slice 3 (the Arm A/B Agent-OS hosting spike — stays on #13033 with Ada's four-falsifier gate) · tray/app lifecycle (ADR 0034 E8) · packaging/signing/update (E6/E7) · the NL bridge wiring into the shell-booted app (follow-up once slice 3 lands the Brain).

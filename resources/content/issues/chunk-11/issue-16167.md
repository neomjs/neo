# Dogfood the canonical Docker Agent OS on a maintainer machine

## Context

Native child of #15798 (the live GitHub parent edge is set). The epic is not
complete when an isolated parity Compose file and CI lane exist; it is complete
when a real maintainer machine uses the container topology as its normal local
Agent OS runtime.

#15803, #15805, #15807, #15990, and #15992 delivered the container stack,
generated remote adapters, CI coverage, and authentication substrate. This leaf
consumes those pieces in the environment they were meant to replace.

Discussion #15605 is a downstream application of this outcome: local
multi-tenant fixtures and membership debugging need the local container topology
first. They are not part of this single-operator cutover.

## Problem

Live audit at `dev@8849ca155d910bf608e8580c5ba8886280372be1` on
2026-07-30 found:

- Docker unavailable at `/var/run/docker.sock`; `docker info` cannot connect.
- `npm run ai:orchestrator` still runs from the host checkout and owns mixed
  host-edge plus container-capable work.
- resident harness sessions still spawn many per-harness stdio Memory Core and
  Knowledge Base writer processes.
- the dev parity stack uses an isolated overlay plane; no supported lifecycle
  re-elects the existing canonical local plane into that container shape.

Stopping the host orchestrator today removes Chroma and wake delivery. Starting
Docker ad hoc risks duplicate owners. Copying parity data into the durable plane
would be the wrong model: the canonical bytes already exist and need a cold,
reversible ownership handoff.

## Architectural reality

- #16166 defines the single-owner split: host edge for unavoidable machine-local
  effects; container plane for cloud-capable work.
- #15800 owns profile placement plus port and served-identity contracts.
- #15805 / PR #16053 generated remote MC/KB adapters while keeping the local
  stdio projection reversible.
- #15806 / PR #16037 delivered snapshot, replay, disposition, and latency
  diagnostics for an isolated pilot plane. Its certifying promotion and clean
  demotion terminals intentionally remain closed without real producers. This
  ticket does not pretend that parity data can be promoted.
- ADR 0019 requires profile-owned config truth; local untracked overrides may
  select a profile but must not redefine it.
- ADR 0014 keeps wake delivery at the host edge. Retiring `legacy-mixed` means
  removing its container-capable ownership, not losing wake delivery.

## Fix — one coherent PR plus an operator-run receipt

Provide a supported local-dogfood lifecycle that:

1. builds exact-head Neo images outside the readiness window and pins observed
   Chroma/Caddy image identities;
2. preflights Docker, normalized Compose, ports/PIDs, file-backed secrets,
   provider reachability, generated-config freshness, a fresh restorable logical
   backup, full-plane copy-on-write snapshot capability, and the #16166 ownership
   matrix;
3. rejects resident stdio writers and any partially running replacement topology
   before the first signal;
4. stops the verified legacy owner and children, snapshots the complete canonical
   plane plus external symlink root, and projects only container-owned scheduler
   cadence into a separate container-plane state file;
5. starts the container plane directly on the existing canonical bytes, proves
   authenticated MC/KB served identity through one loopback ingress, then starts
   host-edge in the legacy scheduler directory with wake delivery live;
6. provides idempotent status plus an ordered safe stop: close ingress, drain
   memory/message WALs, stop orchestrator, KB/MC, then Chroma, verify zero
   replacement owners, merge split cadence, and only then restart
   `legacy-mixed`.

The PR owns the executable lifecycle, safety gates, receipts, and operator
documentation. The actual machine cutover is post-merge validation on this ticket
because it changes long-running local state and requires operator authority over
the desktop/container runtime.

## Contract Ledger

| Surface | Source of authority | Required behavior | Failure / rollback | Evidence |
|---|---|---|---|---|
| Container lifecycle | checked-in dogfood command/profile | Idempotent build/preflight/start/status/safe-stop | Missing runtime, partial topology, stale image, collision, or bad secret fails before mutation | command unit/static tests + live receipt |
| Data plane | #15799/#15800 plane identity and placement | Containers bind the existing canonical root and every external symlink root | full-plane COW snapshot before state mutation; never copy parity data into canonical | rendered binds + snapshot manifest + served identity |
| Task ownership | #16166 | container-plane and host-edge have exactly one owner per task | matrix or fresh-receipt mismatch blocks startup | machine-readable two-role receipts |
| Scheduler continuity | orchestrator task-authority SSOT | split roles retain their owned cadence; legacy rollback receives the latest value from each owner | atomic projection/merge; stale PID fields cleared | state projection/merge specs |
| Seat transport | #15805 generated adapter authority | resident seat uses HTTP MC/KB; NL/GitHub Workflow remain local | stdio opt-out remains exact | generated-config readback + consumed calls |
| Safe stop | checked-in lifecycle | ingress closes first; both WALs drain; data services stop in dependency order | legacy restart forbidden until replacement shutdown is positively proven | ordered transition receipt |
| Host edge | ADR 0014 | wake daemon is live under `host-edge`; no legacy mixed owner remains | host edge can restart without touching container owners | live PID command + fresh authority receipt |

## Decision Record impact

**ADR 0019 preserved.** The lifecycle resolves declared AiConfig values at the
entrypoint and projects them into Compose; no consumer-local default or env
re-derivation is introduced.

**ADR 0014 preserved.** Wake delivery remains host-local and independently
restartable.

## Acceptance Criteria

- [ ] One checked-in bounded command family performs build, preflight, start,
  status, and safe stop for the canonical local Docker Agent OS.
- [ ] Preflight rejects missing Docker, partial replacement owners, occupied
  elected ports, foreign PIDs, active stdio writers, unresolved or mounted secret
  files, stale/unknown image provenance, unreachable/secret-backed provider
  routes, stale config/backup evidence, non-COW snapshot sources, plane mismatch,
  and incomplete #16166 authority.
- [ ] The container plane binds the existing canonical root plus its external
  symlink root and serves authenticated Memory Core and Knowledge Base with the
  expected `{plane.id, plane.dataRoot}` through `127.0.0.1:3102`.
- [ ] Exact-head Neo source is packaged in the three Agent OS images; Chroma and
  ingress run by observed immutable image id; no mutable repository bind or
  credential-bearing `.env` shadows an image.
- [ ] `legacy-mixed` and `host-edge` are mutually exclusive occupants of the
  legacy scheduler directory; container-plane uses its own projected task-state
  file; every authority row has exactly one live owner.
- [ ] Failed start containment never restarts legacy until host and Docker
  replacement owners are proven stopped; rollback atomically merges the latest
  host/container cadence first.
- [ ] Safe stop requires an explicit seat-quiesced acknowledgement, re-checks the
  writer census, closes ingress first, drains both WALs, and stops services in the
  documented dependency order without `down` or volume deletion.
- [ ] At least one resident maintainer seat consumes generated HTTP MC/KB entries;
  its stdio opt-out remains exact; NL and GitHub Workflow stay local; wake is
  proven through the independent host-edge process.
- [ ] Reboot guidance restores the same exact images, owners, plane, and
  file-backed secret references without interactive env re-entry.
- [ ] The post-merge maintainer-machine receipt records source head, image ids,
  backup/snapshot evidence, plane id, provider route, ownership matrix, consumed
  MC/KB calls, wake delivery, and safe-stop/rollback result.

## Out of scope

- Replacing the host wake mechanism.
- Deleting stdio.
- Containerizing Fleet Manager.
- Multi-tenant membership, identity, fixtures, or admission (Discussion #15605).
- Solving all deployment-default redundancy (#16039).
- General multi-machine installation packaging.

## Avoided traps

- **Parity-data promotion:** the canonical bytes are the source; ownership moves.
- **Green Compose health as dogfood:** does not prove served plane, image identity,
  resident-seat consumption, or wake delivery.
- **Overlay-only success:** proves isolation, not replacement of the canonical
  local runtime.
- **Stopping the host before authority/process audit:** creates an outage, not a
  cutover.
- **Keeping both supervisors temporarily:** makes duplicate work the steady state.
- **Restarting legacy after an uncertain shutdown:** creates duplicate writers;
  uncertainty settles failed-contained.
- **Timed image builds:** confounds deployment setup with runtime readiness.
